# 🚗 java-racingcar-precourse

## 🎯 구현할 기능 목록

### 입력 관련
- [ ] 경주할 자동차 이름을 입력받는다.
    - 쉼표(,) 기준으로 구분한다.
    - 이름이 5자를 초과하면 `IllegalArgumentException`을 발생시킨다.
    - 쉼표 이외의 구분자를 사용하면 `IllegalArgumentException`을 발생시킨다.
- [ ] 시도할 횟수를 입력받는다.
    - 숫자가 아닌 문자를 입력할 경우 `IllegalArgumentException`을 발생시킨다.

---

### 게임 진행
- [ ] 입력받은 시도 횟수만큼 반복한다.
- [ ] 각 자동차는 0~9 사이의 무작위 값을 생성한다.
    - 값이 4 이상이면 전진한다.
    - 값이 3 이하이면 멈춘다.
- [ ] 각 시도마다 자동차의 이름과 이동 결과(`-`)를 출력한다.

---

### 결과 출력
- [ ] 경주 완료 후 가장 멀리 이동한 자동차(또는 공동 우승자)를 계산한다.
- [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.
    - 예시: `최종 우승자 : pobi, jun`

---

### 예외 처리
- [ ] 잘못된 입력(구분자 오류, 이름 길이 초과, 숫자 외 문자 입력 등)이 발생하면  
  `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
